# -Smart-Routing-Split-Tunneling
Автообновляемые списки маршрутизации и раздельного туннелирования (Split Tunneling) для AmneziaVPN, Sing-box и v2rayN на базе GitHub Actions.
# 🧭 Свобода от Орды — Smart Routing

Автоматически обновляемый набор правил маршрутизации (Split Tunneling) для VPN-клиентов. Позволяет направлять через VPN только нужные ресурсы, оставляя локальные сервисы, банки и игры на прямом соединении без потери скорости и пинга.

Вся сборка, фильтрация и публикация списков работает автоматически через **GitHub Actions**.

## ⚡ Зачем это нужно

* **Максимальная скорость:** видео, YouTube, Discord и заблокированные сайты идут через VPN, а локальные сервисы работают напрямую на скорости провайдера.
* **Свежие базы каждый день:** **GitHub Actions** запускает скрипт сборки каждые 24 часа, удаляет дубликаты и оптимизирует списки.
* **Никакой ручной рутины:** не нужно каждый раз перекачивать файлы — клиент сам подтягивает изменения по прямой ссылке из репозитория.

## 📱 Как подключить в AmneziaVPN

1. Откройте **AmneziaVPN** → перейдите в **Настройки → Раздельное туннелирование (Split Tunneling)**.
2. Выберите режим **«Только сайты из списка»**.
3. Нажмите **«Импорт»** и вставьте ссылку на `amnezia-sites.json` (или скачайте файл из папки `dist/`).
4. Сохраните настройки и переподключитесь к серверу.

## ⚙️ Архитектура проекта

* `scripts/build_lists.py` — Python-скрипт, который объединяет источники, валидирует домены и конвертирует их в форматы для разных VPN-клиентов.
* `custom/include.txt` — ручной список важных доменов, которые всегда попадают в итоговую сборку.
* `custom/exclude.txt` — список исключений (домены, которые гарантированно идут в обход VPN).
* `.github/workflows/update-lists.yml` — воркфлоу **GitHub Actions**, запускающий сборку по расписанию (`cron`) и коммитящий результат в ветку `main`.
